# ERP Plus Organization Standards

This repository contains the organization-wide standards, governance policies, contribution workflows, and community health files used across the ERP Plus GitHub organization.

These files are automatically inherited by repositories that do not define their own local versions.

---

## Purpose

This repository serves as the central source of truth for:

- Contribution standards
- Community guidelines
- Security policies
- Pull Request templates
- Issue templates
- Incident reporting workflows
- Repository governance

## Governance Scope

These standards apply to:

- Core ERP Plus repositories
- Rails Engines
- Documentation repositories
- Future repositories created under the organization

Repositories may override templates locally when necessary.

### Minor Releases

- New issue templates

Examples:

- Governance model changes
- Contribution process redesign
- Workflow redesign
